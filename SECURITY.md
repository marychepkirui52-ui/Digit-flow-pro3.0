# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Digit Flow Pro, please email marychepkirui52@gmail.com with:

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if available)

Please do NOT create a public GitHub issue for security vulnerabilities.

## Security Best Practices

When using Digit Flow Pro:

1. **API Token Safety**
   - Never share your Deriv API token
   - Never commit tokens to version control
   - Use environment variables for sensitive data
   - Regenerate tokens if compromised

2. **Account Security**
   - Use strong, unique passwords
   - Enable 2-factor authentication on Deriv
   - Use demo accounts for testing
   - Never trade with funds you can't afford to lose

3. **Data Protection**
   - Run locally for sensitive operations
   - Keep your browser and OS updated
   - Use HTTPS connections only
   - Clear browser cache regularly

4. **Bot Security**
   - Review bot logic before deployment
   - Test with small amounts first
   - Monitor trades actively
   - Set stop-loss limits
   - Regular backups of configurations

## Vulnerability Disclosure Timeline

- Report received → Acknowledgment within 24 hours
- Investigation → 7-14 days
- Fix development → 14-30 days
- Public disclosure → After fix is released

## Version Support

Security updates are provided for:
- Current version: Full support
- Previous version: Limited support
- Older versions: No support

Always keep your application updated.
