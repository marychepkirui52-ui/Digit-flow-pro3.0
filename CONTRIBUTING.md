# Contributing to Digit Flow Pro

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/Digit-flow-pro3.0.git`
3. Create a feature branch: `git checkout -b feature/my-feature`
4. Install dependencies: `npm install`
5. Start development: `npm run dev`

## Code Style

- Use ES6+ syntax
- Functional components with hooks
- Clear variable naming
- Add comments for complex logic
- Format code with consistent indentation (2 spaces)

## Testing

- Test with demo account first
- Verify all features work as expected
- Test on multiple browsers
- Check mobile responsiveness

## Commit Messages

- Use clear, descriptive commit messages
- Format: `type: description`
- Types: `feat:`, `fix:`, `docs:`, `style:`, `refactor:`

Example: `feat: add RSI indicator to analysis panel`

## Pull Requests

1. Update documentation if needed
2. Add description of changes
3. Reference related issues
4. Request review from maintainers

## Reporting Bugs

Include:
- Browser and OS information
- Steps to reproduce
- Expected vs actual behavior
- Screenshots if applicable

## Feature Requests

Describe:
- Use case and benefits
- Potential implementation approach
- Any concerns or limitations
